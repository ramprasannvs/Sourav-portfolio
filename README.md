# Sourav-portfolio

Personal Portfolio Website for **Sourabh Singh Rawat** — Customer Service Executive, Customer Support & International Voice & Chat.

Built with **React 19**, **Vite**, **Tailwind CSS**, and **shadcn/ui** design patterns.

## Features
- **Executive Profile & Hero Section**: Direct CTAs, downloadable resume, and candidate overview.
- **About Me**: Operational standards, US staffing experience, and core service background across EST, CST, and PST time zones.
- **Professional Experience**: Chronological history covering all 7 roles and achievements based strictly on resume data.
- **Core Skills & Tools**: Categorized skill tags and ATS/CRM/productivity tool badges.
- **Education & Additional Strengths**: Academic degree, DCA, ITI, typing speed (60 WPM English & Hindi), and key strengths.
- **Direct Contact Section**: Interactive mail client link and a pre-filled message generator.
- **Mobile Responsive**: Tested across mobile, tablet, and desktop viewports with fluid typography, responsive grids, and iOS-safe input font sizing.
- **Embedded Resume PDF**: Instant client-side resume download.

## Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm or pnpm

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
```
